Typographic Conventions and User Interface


Typographic Conventions

  • Generic vs Specific Instructions:
    Your project assignment document may have sections, sub-sections and specific numbered instructions are either “generic” or "specific" to a particular operating system or Git server. When there is a list of instructions that vary for each specific system, these instructions are numbered using Greek letters: α,β, γ, etc. -- this indicates the reader should perform only one of the listed instructions.

    • Server:  Your instructor will tell you which Git server you will use for your course work. It will be one of the following:
      • cci-git.uncc.edu
      • bitbucket.org

      Instructions in this document that are specific to one of the above Git servers will have the following headings:

      • [YourServer=cci-git]
      • [YourServer=Bitbucket]

      As long as you configure the settings in the Document Configuration section (above), then the detailed instructions will only be displayed for the Git server you selected (while the details for the other servers will remain hidden).

    • Operating System: Your instructor will tell you which operating systems you must use for your course work. Instructions in this document that are specific to a particular operating system will have the following headings:
      • [OS=Windows]
      • [OS=Linux]
      • [OS=Mac]

      Depending on the course you are taking you may be required to use only one designated operating system. This information will be given to you in class.

      As long as you configure the settings in the Document Configuration section (above), then the detailed instructions will only be displayed for the operating system you selected (while the details for the other os's will remain hidden).

  • Fonts:
    • your_user_id – this indicates you should input a specific text string. The specifics will be indicated in the instructions.
    • path_to_a_directory_where_you_can_save_your_work – this indicates you should input a specific text string. It is assumed the reader can interpret what to type based on the context and their general computer science knowledge.
    • […additional output will appear…] – this a comment describing output from a command-line command.
    • Post-publication corrective markup:
      1. Elaboration on instructions - this highlighting indicates the highlighted text was inserted after original publication of the assignment. Mouse hovering on the text may display additional information about the date/time of the correction.
      2. Solve this problem using depth first search - this font typeface indicates the text was deleted after original publication of the assignment and is no longer correct. Mouse hovering on the text may display additional information about the date/time of the correction.
  • Shell Code Examples: Shell code instructions appear in black boxes. For lengthy code examples there is an interactive scroll bar on the right.       1. Mouse hovering over the document's instruction items auto highlights the hovered item.   Note, Q&A mode generally will highlight in inner most instruction item over which the mouse hovers.

      3. The new tab contains an Gmail compose email window with a pre-composed email.  The emails content contains a copy of the document text you selected and is addressed to the class's Google Group.

  • Rubric Table Columns
    • Full/Partial -
      • Checkbox
        • A checkbox can be checked or unchecked with a border style: solid or dashed
        • Manually checking a checkbox-awards full points for the Instruction item and sets the style solid..
          If the Instruction Composite, all descendent substep Instructions are each awarded full points, box checked, and style solid.
        • Manually unchecking a checkbox-awards zero points (style remains solid)..  Further:
          • All ancestor Composite Instructions are set to unchecked, styled dashed, and their cumulative points are recalculated..
          • If the unchecked Instruction itself is Composite, all descendent substep Instructions are unchecked, awarded 0 points, and styled solid..
