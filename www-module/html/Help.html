    • - When pressed this button switches the cursor to "Q&A selection text mode".  You select part of the assignment document for which you have a question and Q&A mode create a pre-compose email for posting a question to the class Google Group.  
      In detail, the Q&A mode works as follows:
      1. Mouse hovering over the document's instruction items auto highlights the hovered item.   Note, Q&A mode generally will highlight in inner most instruction item over which the mouse hovers.
      2. When you left click on the highlighted part, the mouse exits Q&A mode and a new tab opens in the browser.
        For the new tab top open properly, you must be logged into your UNCC gmail account in another tab in the same browser.
      3. The new tab contains an Gmail compose email window with a pre-composed email.  The emails content contains a copy of the document text you selected and is addressed to the class's Google Group.
      4. You then add your question about the selected document text and send the message to the class Google Group.

  • TA Mode - TA Mode enables features for grading.  This include alternate display of the Rubric table and GUI menu for exporting the graded rubric to a local .html file.
    • Menu Bar
      • Opens TA Rubric drop down menu.
        • Choose File - unimplemented
        • Export - exports the current rubric to a self contained .html with the rubric checkbox scoring and feedback comments
    • Rubric Table  - 
      • Points Table Column - 
        • Checkbox toggling:
          • A checkbox can be checked or unchecked with a border style: solid or dashed
          • Manually checking a checkbox | Awards full points for the Instruction item and sets the checkbox border style solid..
            If the Instruction is Composite, all descendent substep Instructions are each awarded full points, their boxes are checked, and with solid line style.
          • Manually unchecking a checkbox | Awards zero points (style remains solid)..  Further:
            • All ancestor Composite Instructions are set to unchecked, styled dashed, and their cumulative points are recalculated..
            • If the unchecked Instruction itself is Composite, all descendent substep Instructions are unchecked, awarded 0 points, and styled solid..
